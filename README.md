# Модульний контроль 1 — Вступ до мобільної розробки

Дисципліна: **Програмування для мобільних платформ**
Змістовий модуль 1 (теми 1–8). Частина 2 — практичні завдання (Dart / Flutter).

## Структура

| Завдання | Файл | Що демонструє | Запуск |
|---|---|---|---|
| 1 | `lib/task1_library.dart` | Класи, абстракція, колекції (`where`, `map`) | `dart run lib/task1_library.dart` |
| 2 | `lib/task2_rating_badge.dart` | Власний `StatelessWidget` `RatingBadge` | `flutter run -t lib/task2_rating_badge.dart` |
| 3 | `lib/task3_counter_navigation.dart` | `setState`, `Navigator.push/pop`, передача даних через конструктор | `flutter run -t lib/task3_counter_navigation.dart` |
| 4 | `lib/task4_weather_service.dart` | `Future`, `async/await`, `Stream`, `async*` | `dart run lib/task4_weather_service.dart` |

## Вимоги

- Flutter SDK 3.19+ (Dart 3.3+)
- Для завдань 2 і 3 потрібен емулятор, пристрій або `-d chrome`

## Перший запуск

```bash
flutter pub get
```
